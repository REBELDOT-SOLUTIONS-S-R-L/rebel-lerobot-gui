Create an app to manage and control LeRobot devices.

The app has to have a GUI with panels as described in PROJECT_DESCRIPTION.md
Use react and electron to create the interface.
The app should run on Linux, macOS, and Windows. Adapt scripts, paths, and ports to the OS.

The LeRobot repository can be found here: https://github.com/huggingface/lerobot
Instructions on how to install and use it are here: https://huggingface.co/docs/lerobot/main/en/installation
Here is a list of common lerobot instructions: https://huggingface.co/docs/lerobot/main/en/cheat-sheet

The robot and leader images can be found in assets folder.
There shoudl be indicators pointing from each motor and information about the motors to the sides of the image. There are 6 motors (5 for joints and 1 for gripper).
